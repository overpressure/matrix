**Before you ask**

1. Say which headset, which computer (Linux, Windows or macOS) and which overpressure version.
2. Say what you did and what happened, with the exact error text.
3. If the installer stopped, click "Save logs…" and attach the zip to a GitHub issue rather than here: logs belong with the bug, and an issue doesn't scroll away.

One thread per problem keeps answers together. When it's solved, say what fixed it.
